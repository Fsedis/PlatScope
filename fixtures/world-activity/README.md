# Пример текущего Возрождения Прайм

`resurgence.json` — публичный ассортимент Варзии из `https://api.warframestat.us/pc?language=en`, полученный 5 сентября 2026 года, и связанные записи общедоступных справочников предметов/рынка. Снимок сокращён до шести предметов снаряжения, шести реликвий и их наград. Инвентаря, истории освоения или других данных аккаунта здесь нет.

`resurgence-offers.json` — результат сопоставления этого примера в ядре приложения. Тест `resurgence_maps_real_rotation_to_warframes_and_exact_relic_rewards` проверяет полное совпадение результата с этим файлом. Фоновый браузер использует его в режиме `?mock=1&mockWorld=real`; таймеры и отметки освоения в таком режиме демонстрационные.

Проверяемые особенности: обеим прайм-варфреймам соответствуют все шесть реликвий, Акболто — пять; Форме не назначается комплект; двойной чертёж Формы не превращается в один; редкий чертёж Мираж в Лит M7 имеет шанс 2% без улучшения.
