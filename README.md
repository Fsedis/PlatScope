# PlatScope

PlatScope — локальное Windows-приложение для торговли в Warframe. Оно объединяет инвентарь, цены, историю рынка, ордера Warframe Market и подсказки по заработку в одном интерфейсе.

## Что умеет приложение

- **Рынок** — поиск предметов, текущие ордера, собственные продажи и подтверждённые игрой сделки.
- **Мои предметы** — продаваемый инвентарь, точный ранг и вариант, свободные копии, цена, продажи в день и тренд цены за 90 дней.
- **Надетые моды** — показывает, на каком предмете и в какой конфигурации установлена каждая копия мода.
- **Возможности** — подсказывает, какой комплект дособрать, какую реликвию открыть, что обменять на дукаты и как выгоднее использовать накопленные ресурсы.
- **Помощник наград** — распознаёт русский экран выбора награды реликвии и показывает цену, дукаты, количество копий и прогресс комплекта поверх Warframe.
- **Настройки и диагностика** — ручное обновление данных, параметры оверлея, состояние источников и безопасный диагностический отчёт.

Инвентарь обновляется только по явной команде пользователя. Scanner читает активную сессию запущенного PC-клиента Warframe с правами `PROCESS_VM_READ`, запрашивает инвентарь у Digital Extremes и сразу уничтожает временные реквизиты. Записи в память, hooks и injection отсутствуют.

## Быстрый запуск для разработки

После установки Rust, Node.js, pnpm и .NET 8:

```text
pnpm install --frozen-lockfile
START_PLATSCOPE_DEV.bat
```

Bat-файл запускает Tauri в режиме разработки без полной упаковки установщика. Подробности и команды проверки находятся в [документе о сборке](docs/BUILD.md).
