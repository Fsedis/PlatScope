# PlatScope

PlatScope — локальное Windows-приложение для торговли в Warframe. Оно объединяет инвентарь, цены, историю рынка, ордера Warframe Market и подсказки по заработку в одном интерфейсе.

## Что умеет приложение

- **Сейчас в игре** — циклы локаций, торговцы, Возрождение Прайм, ближайшие сбросы и настраиваемые напоминания.
- **Охотник за наградами** — поиск текущих заказов по нужной награде, сравнение шансов и оценка стоимости добычи.
- **Рынок** — поиск предметов, свои объявления о продаже и покупке, статистика за 7/30/90 дней и история подтверждённых игрой сделок с выгрузкой CSV.
- **Мои предметы** — инвентарь с точным рангом и вариантом, количество к продаже, текущие предложения продавцов и подготовка объявления. В режиме **Освоение** доступна история освоения снаряжения.
- **Надетые моды** — показывает, на каком предмете и в какой конфигурации установлена каждая копия мода.
- **Возможности** — подсказывает, какой комплект дособрать, какую реликвию открыть, что обменять на дукаты и как выгоднее использовать накопленные ресурсы.
- **Помощник наград** — распознаёт русский экран выбора награды реликвии и показывает цену, дукаты, количество копий и прогресс комплекта поверх Warframe.
- **Настройки** — ручное обновление данных и параметры оверлея. Состояние источников, сохранённых данных и диагностический отчёт доступны через кнопку «Открыть диагностику» внизу настроек.

Инвентарь обновляется автоматически при обнаружении запущенной игры, после миссий и переходов между локациями. Переключатель **Автообновление** в «Моих предметах» включён по умолчанию; его можно выключить и обновлять инвентарь вручную. Фоновое обновление работает при запущенных PlatScope и Warframe. Магазин Норы загружается отдельно при отсутствии актуального ассортимента, а не после каждой миссии.

Сканер читает активную сессию запущенного PC-клиента Warframe с правами `PROCESS_VM_READ`, запрашивает инвентарь у Digital Extremes и сразу уничтожает временные реквизиты. Записи в память, hooks и injection отсутствуют.

## Быстрый запуск для разработки

После установки Rust, Node.js, pnpm и .NET 8:

```text
pnpm install --frozen-lockfile
START_PLATSCOPE_DEV.bat
```

Bat-файл запускает Tauri в режиме разработки без полной упаковки установщика. Подробности и команды проверки находятся в [документе о сборке](docs/BUILD.md).
