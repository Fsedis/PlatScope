# PlatScope 0.1.91

В разделе «Отряд и билды» кнопка «Сохранить экипировку» теперь сохраняет всю полученную экипировку сопартийца одним билдом, независимо от выбранного предмета.

В сохранённом билде можно переключаться между предметами. Поиск учитывает весь состав, а копирование и экспорт в текстовый файл включают всю экипировку и доступные улучшения.

Старые билды с одним предметом, их названия и заметки остаются доступны. Для сохранения полного комплекта такого сопартийца нужно получить его экипировку и сохранить заново. Сохранение отдельной конфигурации из памяти по-прежнему не приписывает её сопартийцу.
