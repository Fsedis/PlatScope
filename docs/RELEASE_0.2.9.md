# PlatScope 0.2.9

- В «Плане прокачки» появился учёт кузницы: «Изготавливается», «Готово — заберите» и время завершения. Материалы, чертежи и кредиты уже запущенного изготовления исключены из оставшихся затрат. После получения предмета обновите инвентарь из Warframe.
- В «Материалах и компонентах» можно раскрыть «Как изготовить компонент»: чертёж, сырьё, количество запусков, выход партии, время и стоимость. Учитываются готовые детали, результаты кузницы и остатки предыдущих партий. Рецепты раскрываются на один уровень.
- В «Моём плане» показаны общий список материалов и кредиты на оставшийся план. Запасы распределяются по порядку предметов; многоразовый чертёж учитывается один раз, а его получение в следующем шаге отмечается как запланированное ранее.
- Ещё не освоенное снаряжение защищено от расходования как ингредиента, включая копии, ожидаемые из кузницы. При неизвестном рецепте, цене или времени завершения план сообщает о неполных данных.
- Готовность кузницы пересчитывается раз в минуту, включая промежуточное завершение нескольких партий. Ошибка загрузки не отменяет следующий пересчёт.
- Старый справочник автоматически обновляется для загрузки рецептов компонентов. Старый снимок инвентаря без данных кузницы требует нового чтения Warframe.
- Подбор реликвий учитывает оплаченное изготовление и получение чертежа, уже включённое в план: повторно добывать их для того же шага не требуется. Для недостающих компонентов учитываются их чертежи и сырьё.

План показывает необходимые действия; покупки и изготовление выполняются в игре. Внешний вид и игровой сценарий проверяет пользователь.
