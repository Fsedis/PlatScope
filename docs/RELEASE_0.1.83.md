# PlatScope 0.1.83

- Переработана вкладка «Миссия»: фильтры слева, большая карта в центре, поиск и выбранный объект справа. Основные действия помещаются на экране 1920×1080. Настройки высоты, технические сведения и запись раскрываются по запросу.
- Добавление в свою группу теперь выполняется сразу кнопкой + рядом с ней. Новая группа создаётся с выбранными предметами и предложенным названием. Название, цвет и состав редактируются на месте; последнее изменение можно отменить. Сохранённые фильтры продолжают работать.
- Одинаковые экземпляры в списке объединяются с указанием количества. Разные варианты, состояния тайников и отдельные игроки не смешиваются. Можно вернуться к полному списку или выделить результаты поиска для добавления в группу.
- Предметы из пользовательских фильтров получают приоритетный поиск новых экземпляров каждый секундный проход. Дополнительное чтение ограничено 16 МиБ блоков и примерно 100 мс обработки, без сброса карты и записи дампов.

При большом количестве блоков обнаружение конкретного нового предмета может занять больше секунды. Поиск работает в областях, подтверждённых первоначальным чтением; совсем новые области памяти требуют ручного поиска.

Проверены основные действия с фильтрами, сохранение после перезагрузки, пустое состояние и управление картой на 1920×1080. Целевые проверки поиска и фильтрации пройдены. Исправление запуска OCR наград из 0.1.82 сохранено.
