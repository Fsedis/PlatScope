# Только необходимые проверки

По требованию владельца проекта обычная правка не требует нового теста. Добавлять проверку следует только для конкретного существенного сбоя: потери данных, ошибочной торговой операции или расчёта, отказа OCR или обновления, неверного чтения памяти либо сброса карты. Сначала дополнять подходящий существующий тест, дубли удалять.

Не закреплять тестами тексты интерфейса, CSS, структуру исходников, тривиальные форматтеры и поведение самих демонстрационных данных. Заметные изменения интерфейса проверять в отдельном фоновом браузере на 1920×1080.

Запускать только проверки изменённого поведения. Полный набор проекта и повторные прогоны без новой причины не нужны. Для удаления тестов достаточно проверки типов/компиляции затронутых файлов; если объединена важная проверка, выполнить её один раз.

Перед релизом обязательны локальная сборка приложения и OCR, создание установщика, проверка подписи, версии, manifest и SHA-256. После публикации проверять скачивание установщика и автообновление. Эти действия не требуют запуска всех тестов проекта.

## Чистка после релиза 0.1.84

Удалены 79 тестов: 73 проверки интерфейса на TypeScript и 6 на Rust; 13 файлов удалены целиком. Убраны проверки CSS, точных подписей, демонстрационных сценариев карты, декоративных изображений и дублирующая проверка смены локации. Условия остановки по разделённой строке журнала сохранены в существующей проверке автозапуска.

Сохранены проверки торговых количеств и точных вариантов, расчётов цен, резервов, сохранения и миграций данных, OCR, ограничений чтения памяти, обнаружения новых объектов, принадлежности игрока, фильтров и обновления карты без сброса. Проверки установщика, подписи и автообновления также сохранены.
