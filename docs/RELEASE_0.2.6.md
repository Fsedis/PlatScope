# PlatScope 0.2.6

Проверка цен в «Моих объявлениях» сохраняет один результат для списка и карточки продавцов. Проверенная оценка больше не заменяется ценой снимка после обновления списка, инвентаря или повторного открытия раздела.

- Ошибка повторного запроса сохраняет последнюю успешную оценку и показывает предупреждение. Запоздавший ответ не отменяет более новую проверку. Если продавцов недостаточно для оценки, совет изменить цену не появляется.
- Статус аккаунта и кнопки рынка выровнены по высоте; группы управления аккуратно переносятся в узком окне.
- С карты миссии убраны всплывающие текстовые плашки. Значки, отметки ↑/↓ и подробности выбранного объекта сохраняются.
- Исправлены изображения призм, включая «Призма: Пылинка», и Сирокко. Обновление справочника восстанавливает картинки в старом кэше.

Локальные проверки расчётов, справочника, сборки и OCR пройдены. Внешний вид и поведение в живой игре проверяет владелец.
