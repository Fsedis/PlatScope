# PlatScope 0.2.1

Исправлен счётчик «Уже есть» в плане прокачки. После обновления инвентаря и изменения плана числа на фильтрах теперь пересчитываются вместе со списком.

- Для старого кэша наличие обычного снаряжения восстанавливается из текущего снимка соответствующего аккаунта. Проданные предметы из истории и отдельные модульные детали не считаются имеющимися копиями.
- Добавлен отдельный фильтр источника чертежа: магазин за кредиты, додзё, выпадение и неизвестный источник. Он работает независимо от наличия материалов, кредитов и готовности к изготовлению.
- Поиск, тип снаряжения и источник одновременно уточняют список и счётчики. Карточка предмета следует выбранным фильтрам; переход к предмету из очереди открывает его в «Моём плане».
