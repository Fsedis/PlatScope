# PlatScope 0.1.76 — запас копий без запрета на продажу

Настройка **«Оставлять копий»** теперь задаёт рекомендуемый запас. Если объявление затронет оставленные себе копии, PlatScope покажет предупреждение и позволит продолжить или вернуться к количеству.

- Можно выставлять копии из общего запаса и менять количество в объявлениях. Уже выставленные копии из этого запаса больше не вызывают ошибочный совет уменьшить объявление.
- Предупреждения учитываются при создании объявления, изменении количества, публикации скрытых объявлений и продаже комплектов.
- Меню **«Оставлять себе: N»** доступно и в инвентаре, и в разделе **Рынок → Мои объявления → Продажа**. Значение общее для обоих разделов.
- Проверки фактического наличия, надетых и непередаваемых копий, личных целей и других активных объявлений сохраняются.

Обновление доступно через встроенную проверку обновлений или установщик ниже. Пакет подписан ключом обновлений Tauri; SHA-256 указан в `SHA256SUMS.txt`.
