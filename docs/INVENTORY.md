# Инвентарь и надетые моды

## Единственный рабочий путь

Инвентарь обновляется кнопкой **Обновить из Warframe**. Старые ручные JSON-форматы и отдельный модуль Overwolf удалены: они не использовались интерфейсом и дублировали встроенный read-only scanner.

Scanner:

1. находит процесс запущенного PC-клиента Warframe;
2. открывает его только с правами чтения;
3. извлекает доминирующую пару `accountId`/`nonce`, build и `ct`;
4. получает JSON у Digital Extremes;
5. обнуляет session info после запроса;
6. нормализует и публикует новый LKG только после полной проверки.

Запись в память, DLL injection, hooks и изменение файлов игры отсутствуют. Метод не является официальным API Digital Extremes и используется на риск игрока.

## Нормализация

Парсер читает только разрешённые категории предметов и не обходит профиль рекурсивно. Поэтому настройки интерфейса и посторонние `/Lotus/Interface/...` строки не могут стать предметами.

Основные правила:

- `RawUpgrades` — точные стеки модов и мистификаторов нулевого ранга;
- `Upgrades` — отдельные экземпляры, ранг которых читается из `UpgradeFingerprint.lvl`;
- отсутствие `lvl` внутри валидного fingerprint означает ранг 0;
- `XP > 0` и другие признаки непродаваемости сохраняются отдельно;
- quantity, rank, размер ответа и число строк имеют жёсткие верхние границы;
- drift необязательной схемы сборок не уничтожает валидный список предметов, но помечает данные о надетых модах как недоступные.

## Exact resolver

Внутренний canonical path сопоставляется с WFM-каталогом отдельно от отображаемого имени. Идентичность рынка включает:

```text
slug + platform + rank + subtype/refinement + stars
```

Если точный вариант не найден или неоднозначен, позиция остаётся в инвентаре, но не получает цену и не становится кандидатом на продажу.

## Количество для продажи

Для каждой строки отдельно хранятся owned, tradeable, untradeable, unknown, equipped и sellable quantities. Продаваемое количество вычисляется после резерва пользователя и защиты надетых экземпляров. Unknown-копия никогда не становится продаваемой по предположению.

## Надетые моды

Scanner сопоставляет уникальные `Upgrades[].ItemId` со ссылками в `Configs[].Upgrades` у варфреймов, оружия, компаньонов, арчвингов, некрамехов и усилителей.

- Один физический экземпляр считается один раз, даже если встречается в нескольких конфигурациях.
- В SQLite вместо raw `ItemId` сохраняется SHA-256-ключ.
- Экран **Надетые моды** группирует размещения сначала по моду, затем по предмету и конфигурации.
- Фильтр в **Моих предметах** позволяет скрыть позиции, у которых нет свободной копии.

## Хранение и обновление

Raw JSON не записывается на диск. В SQLite попадает только нормализованный resolved snapshot, безопасные метаданные, кошелёк/репутация, placements и checksum. Новый снимок атомарно заменяет предыдущий; ошибка запроса или разбора оставляет прежний LKG без изменений.

После обновления каталог может повторно обогатить сохранённый инвентарь русскими именами, изображениями и новыми market mappings без повторного чтения памяти Warframe.
