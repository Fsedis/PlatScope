# PlatScope 0.1.97 — статус хранилища у цены наград

- Рядом с ценой распознанной награды показано, находится ли её предмет в Prime Vault: «В хранилище» или «Не в хранилище».
- Если игровых данных нет или они противоречат друг другу, карточка показывает «Статус неизвестен».
- Строка «У вас» отдельно показывает число личных копий предмета.

Проверены сопоставление награды с данными о хранилище, типы интерфейса, сборка OCR и установщика. Отображение в запущенной игре проверяет владелец.
