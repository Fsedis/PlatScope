# PlatScope 0.1.98 — разломы для моих реликвий

- На экране «Сейчас в игре» показаны действующие разломы, для которых в инвентаре есть реликвии подходящей эры. Разломы Омния учитывают Лит, Мезо, Нео и Акси.
- Для каждой миссии предложена реликвия с наибольшим шансом получить недостающую деталь личной цели. Если такой цели нет, используется доступная оценка платины за открытие. При неполных ценах приложение не выдаёт неизвестную выгоду за ноль.
- Условия показа настраиваются по эре, типу миссии и режиму. Можно добавить несколько условий; они сохраняются автоматически.
- Когда свежесть данных о разломах не подтверждена, приложение не предлагает их как текущие миссии.

Проверены целевые расчёты и обработка данных, интерфейс в широком и узком окне, локальная сборка OCR и Windows-установщика. Игровое поведение и установку на рабочем ПК проверяет владелец.
