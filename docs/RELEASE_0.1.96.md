# PlatScope 0.1.96 — новые награды реликвий

- Награды новых прайм-реликвий, включая детали Цитрины, Стефлоса и Коруфелла Прайм, добавляются в словарь распознавания из актуального рыночного каталога.
- Восстановлено обновление игровых данных после изменения формата источника WFCD: русские названия и сведения о деталях теперь загружаются из новых файлов.
- После обновления приложения игровые данные запрашиваются заново. Это возвращает состав комплектов и стоимость деталей в дукатах.

Проверены загрузка и нормализация актуальных данных, состав новых реликвий и прицельные проверки OCR-каталога. Распознавание в запущенной игре проверяет владелец.
