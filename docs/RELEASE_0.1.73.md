# PlatScope 0.1.73 — личные сборки

В **Возможности → Мой план → Собрать для себя** можно выбрать комплект Прайм для своей коллекции. Уже имеющиеся детали сразу засчитываются, а приложение показывает точное недостающее количество, подходящие реликвии и изображения предмета и деталей.

Когда все нужные копии есть в инвентаре, цель автоматически переходит в **Выполнено**. Приложение один раз сообщает об этом и сохраняет результат после перезапуска. Цель означает сбор полного комплекта деталей; изготовление предмета в кузнице для её выполнения не требуется.

До удаления цели один комплект защищён от продажи и обмена на дукаты. Лишние копии доступны с учётом общего запаса и других целей. Общие детали распределяются без повторного использования. Если детали позже потрачены, карточка показывает текущий остаток, а выполненная цель сохраняется.

Прежний торговый план находится в **Мой план → Заработать платину**. Существующие ордера на Warframe Market автоматически не меняются.

Обновление доступно через встроенную проверку обновлений или установщик ниже. Пакет подписан ключом обновлений Tauri; SHA-256 указан в `SHA256SUMS.txt`. Коммерческого сертификата Authenticode нет, поэтому Windows может показывать предупреждение о неизвестном издателе.
