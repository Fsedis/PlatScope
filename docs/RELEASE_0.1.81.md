# PlatScope 0.1.81

- Положение вашего персонажа и направление камеры обновляются до 20 раз в секунду отдельным адресным чтением. Остальные игроки, предметы и состояния тайников — примерно раз в секунду.
- Новый режим «По взгляду» поворачивает карту вслед за камерой и включает следование за собой. При временной потере данных вид сохраняется. Направление ещё нужно сверить в живой миссии, особенно при переходе в Оператора и наблюдение.
- Геометрия передаётся один раз для сцены; последующие обновления содержат изменения объектов. Фон карты кэшируется до изменения вида.
- После временной ошибки загрузки карта восстанавливается автоматически, сохраняя масштаб и положение.
- Тайники можно отбирать по состоянию. Открытые точки тусклее; добавлены ближайший закрытый тайник, выбор цели, расстояние по прямой, разница высот и сортировка по близости.

Дампы для живой карты не записываются. Полные сканирования автоматически не повторяются.
