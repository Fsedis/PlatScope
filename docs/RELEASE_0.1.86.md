# PlatScope 0.1.86

- Исправлено скрытие врагов: общая подпись «NPC» больше не скрывает все модели сразу. Например, скрытие `SuperMoa_skel.fbx` оставляет другие модели врагов на карте и в списке.
- Для скрытия используется конкретное английское имя или имя модели. При его отсутствии используется конкретное русское название. Общие подписи категорий не служат ключом скрытия.
- Сохранённые записи из 0.1.85 автоматически используют уже записанное в них имя модели; пересоздавать список не нужно. Записи без конкретного имени больше ничего не скрывают.
- В разделе «Скрытые» и подсказках кнопок для таких объектов показывается конкретное имя модели вместо общей подписи.

Пройдена одна целевая проверка: выбранная модель скрывается, другие модели с подписью «NPC» остаются видимыми, сохранённые правила читаются корректно. Проверка Svelte/TypeScript завершилась без ошибок и предупреждений.
