# План прокачки аккаунта

Экран находится в **Освоение → План прокачки**. «Освоение» — отдельный пункт бокового меню в группе «Коллекция». История освоения остаётся в соседнем режиме.

## Как пользоваться

1. Обновите инвентарь из запущенной Warframe. При первом использовании также нужны актуальные данные предметов в настройках.
2. Начните с имеющегося неосвоенного снаряжения или выберите варианты изготовления. Поиск понимает русские и английские названия.
3. Откройте предмет. Карточка показывает следующий шаг, возможные очки освоения, наличие чертежа, цену, условия доступа, материалы и стоимость кузницы.
4. Нажмите **Добавить в план**. Выберите несколько предметов и расставьте их стрелками. Порядок сохраняется отдельно для каждого подтверждённого игрового аккаунта.

Сначала предлагается снаряжение, которое уже есть и осталось освоить. Затем идут варианты с готовыми материалами и чертежом, покупкой чертежа в игровом магазине и одним недостающим видом материала. Снаряжение с неизвестным освоением не выдаётся за новое для аккаунта.

## Чертежи и расчёт материалов

Рецепты, расходники, стоимость и длительность кузницы берутся из `ExportRecipes`. Покупка чертежа за кредиты подтверждается полем `creditsCost` и отсутствием `excludeFromMarket`. Исследования отдельно определяются по `ExportDojoRecipes.research` и `replicatePrice`: цена WFCD `bpCost` сама по себе не означает продажу в игровом магазине.

Для додзё показано условие завершённого исследования; его состояние на аккаунте не прочитано. Требуемый ранг берётся из каталога. Текущий ранг показывается только при наличии соответствующего поля в ответе игры. Если доступ по рангу нельзя подтвердить, предмет не выдаётся за готовый к изготовлению. Неизвестный источник, цена или запас кредитов остаются неизвестными. Покупка готового предмета за платину не используется вместо покупки чертежа.

Для выбранных предметов материалы и кредиты распределяются в порядке плана. Общие запасы не считаются повторно. В карточке выбранного предмета показан остаток после предыдущих шагов. Детали, защищённые личными сборками, исключаются из доступных материалов, включая непередаваемые копии. Полный резерв изготовления не меняет торговый резерв. Ещё не освоенное снаряжение не предлагается потратить как ингредиент. Для рецептов с другим снаряжением отдельно показано, что изготовление его расходует.

Готовое модульное снаряжение определяется по собранной копии и её основной детали. Текущий ранг 0 или отсутствие позолоты не отменяют владение; отдельная деталь в материалах готовой копией не считается. Позолота требуется для подтверждения освоения там, где её требует игра.

План ничего не покупает и не запускает в игре. Он не меняет торговые ордера и резервы. При обновлении инвентаря и каталога расчёт обновляется. Освоенные выбранные предметы остаются в плане с соответствующей отметкой; их можно убрать. Временно исчезнувший из каталога предмет сохраняется в порядке плана с неизвестным статусом.

## Границы данных и проверка

Очки освоения показывают оставшийся потенциал поддерживаемого предмета, а не опыт одной миссии. Для рангов выше 30 могут потребоваться Формы. Рецепты без состава и способы получения, отсутствующие в экспорте, не считаются бесплатным изготовлением. Изготовление промежуточных компонентов автоматически не разворачивается в цепочку: в карточке показаны требуемые готовые ингредиенты. Доступные сведения о выпадении раскрываются по запросу; шанс не гарантирует награду.

Критические проверки: общий бюджет материалов и кредитов, защита личных целей, неизвестный баланс, изоляция планов аккаунтов, сохранность плана при исчезновении каталога и ошибке сохранения, различие магазина и додзё. Внешний вид и действия проверяются в отдельном браузере на репрезентативных данных при 1920×1080 и в узком окне. Это не подтверждение поведения в установленном приложении или реальной игровой миссии.
