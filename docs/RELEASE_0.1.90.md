# PlatScope 0.1.90

На странице «Рынок» появился переключатель статуса Warframe Market: «В игре», «В сети» и «Не в сети».

Статус меняется после подтверждения сервера и синхронизируется с Warframe Market. При ошибке приложение сохраняет последний подтверждённый статус и показывает причину. Во время восстановления соединения переключатель временно недоступен; неподтверждённые изменения не отправляются повторно.

Соединение со статусом поддерживается, пока PlatScope открыт. Индикатор подключённого аккаунта больше не выдаёт подключение за присутствие в сети.
