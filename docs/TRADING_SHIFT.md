# Торговая смена

«Торговая смена» встроена в начало экрана «Рынок». Это рабочая очередь перед торговлей, а не второй экран управления ордерами.

## Что попадает в очередь

- sell-ордер скрыт;
- количество в ордере больше доступного остатка точного варианта;
- цена заметно выше текущего ориентира размещения;
- цена заметно ниже справедливой оценки и предмет можно не сливать;
- ордер не проверялся более 72 часов;
- для точного варианта нет надёжной цены;
- подтверждённая игрой сделка ещё не отражена в WFM-ордере.

Исправные ордера скрыты по умолчанию. Их можно показать одним переключателем. Поиск предметов, история цены и стакан остаются ниже и не дублируются в торговой смене.

## Массовая проверка

Сохранённая оценка загружается локально. Кнопка «Проверить цены сейчас» последовательно получает live-оценку точных вариантов с учётом платформы, ранга, subtype и звёзд. Проверку можно остановить; уже полученные результаты сохраняются на экране.

Перед изменением пользователь видит список `было → станет`. Пакет выполняется последовательно и останавливается на первой ошибке. Каждая запись в WFM по-прежнему проходит backend-границу с `confirmed: true`.

## Подтверждённые сделки

Desktop shell читает только новые строки `%LOCALAPPDATA%\Warframe\EE.log`. Торговый диалог буферизуется не более 120 секунд и становится фактом только после сообщения игры `The trade was successful!`. Повторный маркер не создаёт вторую запись.

Автоматическое сопоставление разрешено только для продажи, где:

1. игрок получил платину и не отдавал платину;
2. английское имя предмета точно совпало с каталогом;
3. найден ровно один sell-ордер;
4. в событии продаётся один сопоставляемый предмет — пакет из нескольких ордеров не выполняется без транзакции;
5. у ордера нет ранга, subtype, charges или звёзд;
6. ордер не изменялся после времени сделки и остаток совместим с `perTrade`.

При любом сомнении интерфейс показывает «Нужна ручная сверка» и не меняет WFM. Даже безопасное совпадение требует нажатия «Отразить в ордере» и отдельного просмотра изменения. Применённое изменение можно отменить: уменьшенный ордер вернёт прежнее количество, закрытый ордер будет создан заново из сохранённого снимка.

Журнал хранит только время, партнёра, платину, названия и количество предметов, статус сверки и снимок выполненного изменения. Это локальный журнал оборота, не расчёт прибыли: стоимость приобретения предмета неизвестна.
