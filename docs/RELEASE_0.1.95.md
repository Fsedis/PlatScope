# PlatScope 0.1.95 — фрагменты декретов в Цепи

- На карте миссии появился отдельный фильтр «Фрагменты декретов», включённый по умолчанию. Он не смешивает фрагменты с энергией, аптечками и ресурсами Дувири.
- Сканер распознаёт фрагмент по проверенному игровому типу, предмету и действию подбора. Точки из предыдущего этапа Цепи не переносятся на текущую арену.
- Подписанный профиль карты дополнен адресом этого типа для сборки Warframe от 26.09.2026. Профили старых сборок сохранены; загружаемые пакеты по-прежнему проверяются подписью.
- Для новых профилей выделен отдельный канал загрузки. Канал версии 0.1.94 остаётся доступен установленным ранее приложениям.

На двоичной записи Цепи подтверждены два фрагмента во втором снимке и их отсутствие после перехода на следующий этап. Работа в запущенной игре и отображение карты проверяются владельцем.
