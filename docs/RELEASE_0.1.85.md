# PlatScope 0.1.85

- Добавлена кнопка «Скрыть» рядом с предметом в списке и действие «Скрыть по названию» в его карточке. Одно нажатие убирает с карты и из списка все экземпляры с тем же полным русским или английским названием, включая новые находки в следующих миссиях.
- Скрытые названия сохраняются между запусками. В разделе «Скрытые» их можно вернуть по одному или все сразу. Включение других групп не отменяет скрытие; счётчики групп и быстрый выбор ближайшего тайника учитывают исключённые предметы.
- Возвращение в Орбитер больше не запускает чтение карты. Предыдущая карта останавливается, приложение ожидает вылета. Следующая миссия запускает карту автоматически. Определение Орбитера использует журнал игры, без чтения памяти.

Проверены скрытие сразу нескольких экземпляров, сохранение после перезагрузки и возврат в интерфейсе на 1920×1080. Две существующие целевые проверки дополнены условиями скрытия и перехода «миссия → Орбитер → миссия»; обе пройдены. Порядок сообщений Орбитера подтверждён текущим EE.log. Поведение установленной версии при следующем живом переходе ещё предстоит проверить.
