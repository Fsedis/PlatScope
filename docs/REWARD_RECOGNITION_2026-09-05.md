# Исправление подмены наград реликвий

## Причина

На присланном фрагменте экрана OCR прочитал второй слот правильно:
«Чертёж: Акбронко Прайм». Затем сопоставление выбрало `bronco_prime_blueprint`
с оценкой сходства 0,846 вместо `akbronco_prime_blueprint`.

В словарь OCR попадали только `primeParts`. Этот список, в свою очередь,
формировался только из успешно разобранных полных сетов. Неподдержанный,
неполный или содержащий повторяющиеся компоненты рецепт удалял из списка
даже корректно сопоставленные награды. В локальном снимке данных из словаря
выпали 20 торговых наград, включая чертёж Акбронко.

## Изменения

- Словарь включает объединение всех торговых наград реликвий и известных
  прайм-деталей. Работает и с прежним кэшем, без ожидания обновления данных.
- Реликвии из журнала не ограничивают награды других игроков.
- Данные о дукатах известных деталей сохраняются независимо от возможности
  корректно рассчитать полный сет. Неполные рецепты по-прежнему не публикуются
  как готовые сеты. Версия игровых метаданных повышена до 9 для фонового обновления.
- Подмена Акбронко / Бронко, Аклекс / Лекс, Аквасто / Васто и Акмагнус / Магнус
  запрещена даже при неполном словаре. Равнозначные кандидаты разных предметов
  больше не разрешаются случайным порядком каталога.
- Короткие названия вроде «Лок» допускают точное совпадение, без нечёткого угадывания.

## Проверка

На неизменённых пикселях подписей из присланного изображения воспроизведены
ошибка старого словаря и верный результат нового. Поскольку прислан фрагмент,
для проверки геометрии он помещён на холст 1920×1080; захват игры не запускался.
Результат: ствол Брэйтона, чертёж Акбронко, чертёж Формы, чертёж Париса.

Автоматические проверки покрывают старый кэш, отсутствующие и повторяющиеся
компоненты рецептов, отсутствующий рыночный сет, порядок кандидатов, парные
названия, перенос названия на две строки и экраны на 2–4 награды. Сетевая
проверка нормализации актуальных публичных данных подтверждает дукаты восьми
наград Акбронко, Аклекс, Аквасто и Акмагнус.

Личная база открывалась только для чтения. Снимок с именами игроков остаётся
в локальных временных файлах и не добавляется в Git. Установленная программа,
окна пользователя и игровые файлы не изменялись. Релиз в этой задаче не выпускался.
