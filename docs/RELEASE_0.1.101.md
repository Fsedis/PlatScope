# PlatScope 0.1.101 — восстановление после зависания OCR

- Распознавание наград ограничено 15 секундами. Если OCR-помощник завис, приложение завершает его и разрешает следующую попытку без перезапуска PlatScope.
- Тайм-аут действует также при передаче каталога помощнику. Определение окна Warframe ограничено 5 секундами.
- Управление OCR и обработка сделок вынесены из общей оболочки приложения в отдельные модули. Правила сопоставления сделок сохранены.

Проверены завершение настоящего зависшего дочернего процесса, освобождение блокировки и успешная следующая попытка. Распознавание поверх игры и установку на рабочем ПК проверяет владелец.
