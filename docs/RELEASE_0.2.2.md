# PlatScope 0.2.2

Добавлено автоматическое восстановление карты после обновлений Warframe, которые меняют адреса данных и сохраняют известную структуру игры.

- Если готового профиля для новой сборки нет, PlatScope самостоятельно ищет новые адреса и проверяет найденные данные перед включением карты. Сбой скачивания профиля не мешает локальной попытке восстановления.
- Успешный результат сохраняется на этом компьютере и повторно проверяется при следующем запуске. Повреждённый сохранённый результат допускает новый поиск.
- Поиск ограничен по времени, поддерживает отмену и в текущем сеансе PlatScope после неудачи не повторяется чаще одного раза в 15 минут для той же сборки игры. Дамп игры не создаётся и не отправляется.
- Если обновление меняет саму структуру данных, карта остаётся выключенной до совместимого исправления. Восстановление после любого будущего обновления не гарантируется.

Проверки выполнены на записях игры от 26 и 29 сентября: восстановлены сцены, проверены повторное использование и исправление повреждённого кэша, а изменённая схема данных отклонена. Владелец подтвердил работу карты в запущенной сборке из исходников.
