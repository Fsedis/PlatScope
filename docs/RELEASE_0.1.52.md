# PlatScope 0.1.52

Исправлены отметки освоения у сетов и наград.

- Освоенное снаряжение отмечено оригинальным игровым лавровым венком.
- Неосвоенные предметы больше не остаются без подписи: видны состояние и прогресс, например 9/30 или 30/40.
- Отсутствующие данные и ошибки загрузки явно обозначены. Они не подменяются нулевым прогрессом.
- Одинаковые отметки используются у готовых и дособираемых сетов, в выбранном плане, наградах реликвий и списке освоения аккаунта.
- Расчёты освоения, количества, цены и ордера не изменены.

Интерфейс проверен в фоновом браузере при 1180×760 и 1920×1080. Управление игрой и масштаб Windows не менялись.

Установщик и подпись обновления собраны локально. Коммерческого сертификата Authenticode нет: Windows может показывать предупреждение о неизвестном издателе. Встроенное автообновление проверяет подпись Tauri.
