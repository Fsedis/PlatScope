# Dashboard

Экран «Обзор» собирает в одном месте локальный снимок портфеля, лучшие кандидаты Sell Now, слабую ликвидность и свежесть данных. Его открытие и кнопка «Обновить сводку» читают только SQLite через существующие application services и не выполняют сетевых запросов.

## Метрики

- **Номинал инвентаря** — сумма `owned quantity × bulk fair price` для всех распознанных точных вариантов. Строки без надёжной цены не подменяются нулевой рыночной оценкой и не входят в сумму.
- **Номинал sellable** — сумма `sellable quantity × bulk fair price` после tradeability и пользовательского резерва `Keep N`.
- **Можно продать** — количество подтверждённых sellable-копий, а не число объявлений или прогноз продаж.
- **Требуют внимания** — unresolved/ambiguous inventory-строки плюс sellable-кандидаты без надёжной цены.

Обе стоимостные метрики являются номинальными. Они не учитывают глубину всего объёма, комиссию, скорость исполнения или возможное движение рынка и не являются прогнозом выручки.

## Кандидаты и ликвидность

«Лучшие кандидаты» — первые четыре оценённых строки из уже рассчитанного Sell Priority. Dashboard не вводит второй алгоритм ранжирования.

Для блока слабой ликвидности используются простые объяснимые диапазоны по closed volume текущего bulk-снимка:

```text
нет fair price или volume -> нет надёжной цены
volume < 5              -> тонкий рынок
volume < 15             -> ограниченный объём
volume >= 15            -> активный рынок
```

Порог — интерфейсный сигнал для проверки, а не гарантия времени продажи. Активные строки не попадают в watch-list.

## Свежесть

Dashboard показывает абсолютную `source_date` рыночного снимка, provider, локальное покрытие истории и готовность offline cache. Подробности и безопасный экспорт остаются на экране «Диагностика».

## Границы

- UI не читает raw upstream JSON.
- Неизвестные цены остаются неизвестными.
- Открытие Dashboard не обновляет provider health и не изображает новую сетевую попытку.
- Переходы в Sell Now, Inventory и Diagnostics используют те же локальные DTO и правила.
