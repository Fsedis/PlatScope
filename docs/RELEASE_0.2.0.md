# PlatScope 0.2.0

План прокачки аккаунта появился в разделе «Освоение», который теперь доступен из бокового меню.

- Приложение подбирает ещё не освоенное снаряжение по текущему инвентарю: уже имеющиеся копии, доступные чертежи и предметы, для которых не хватает одной составляющей.
- Можно выбрать несколько предметов и изменить порядок действий. План учитывает общий запас материалов и кредитов, а также защищает копии для личных целей и ещё не освоенное снаряжение.
- Для чертежей показана возможность покупки в игровом магазине или получения в додзё, если источник подтверждён каталогом. Неизвестные условия доступа не считаются выполненными.
- План сохраняется отдельно для каждого аккаунта. История освоения сохраняет результат после Формы или получения новой копии ранга 0; предметы с пределом 40 требуют освоения до 40.
- Исправлен учёт собранного модульного снаряжения: готовая копия и отдельная деталь различаются.
- Убраны повторяющиеся вводные тексты и очевидные пояснения по всем основным экранам. Полезные данные, ограничения и сообщения об ошибках сохранены.

Сборка, OCR, установщик и подпись обновления проверяются локально. Работу установленной версии в игре проверяет владелец.
