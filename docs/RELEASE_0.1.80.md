# PlatScope 0.1.80

- Тайники Гринир распознаются отдельно от обычных шкафчиков с той же моделью. На карте появилась группа «Тайники» и состояния «Можно открыть», «Открыт» или «Состояние неизвестно».
- Фильтр охватывает все экземпляры выбранного варианта, включая следующие миссии. Полная и короткая запись пути модели больше не разделяют одинаковые ресурсы в правилах по модели.
- Для всех распознаваемых объектов добавлен стабильный признак варианта игрового типа. При добавлении можно выбрать «Этот вариант» или «Все варианты модели»; материалы и связанные действия видны в подробностях объекта.
- До сохранения показано число подходящих объектов. Добавление в существующий фильтр включает его. Сохранённые правила прежней версии продолжают читаться.
- Состояние тайников обновляется адресным чтением известных объектов; периодическое полное сканирование и запись дампов не включаются.

Различение вариантов не означает автоматического определения редкости каждого объекта игры: название и назначение подтверждаются отдельно. Состояние открытия проверено на записи трёх тайников Гринир; при недостаточных или несогласованных данных оно остаётся неизвестным.
