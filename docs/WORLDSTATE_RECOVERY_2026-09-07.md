# Сбой игровых данных и восстановление — 7 сентября 2026

## Причина

На рабочей машине оба маршрута `https://api.warframestat.us/pc?language=en` и
`/pc/syndicateMissions?language=en` вернули HTTP 404 с JSON
`{"message":"WorldState Not Found","error":"Not Found","statusCode":404}`.
Это ответ сервиса, а не отсутствие интернета. Цены `relics.run` и инвентарь DE
в это время успешно загружались. Причина внутреннего сбоя WFCD извне неизвестна.

У PlatScope был один источник для циклов, заказов, публичных продавцов и определения
сезона Норы. «Сейчас в игре» сохранило старый снимок; у заказов был только кэш в памяти.
Кроме того, экран заказов заменял любую причину ошибки советом проверить интернет.

## Исправление

- Общий загрузчик сначала получает полный документ WFCD. При ошибке HTTP, таймауте,
  неправильном формате или устаревшем времени переходит на публичный сервер DE:
  `https://api.warframe.com/cdn/worldState.php`. Никаких реквизитов аккаунта в этих запросах нет.
- Ответ DE имеет заголовок `text/html`, хотя тело — JSON. Исключение типа содержимого
  разрешено только для этого фиксированного URL, с лимитом 4 МиБ и последующим разбором.
- Время сервера проверяется: не более 20 минут назад и не более 5 минут в будущем.
  Нельзя получить новые циклы из страницы ошибки или старого сохранённого документа.
- Все игровые вкладки используют один кэш на 30 секунд и объединяют одновременные запросы.
  После сбоя WFCD повторно проверяется через 5 минут; при сбое обоих серверов действует
  пауза 30 секунд. Один внешний запрос ограничен 4 секундами.
- Активные заказы выбираются по опубликованным интервалам `Activation` / `Expiry`.
  Следующая ротация может присутствовать заранее, но не показывается до начала.
  Собственное окончание заказа Нармер доходит до интерфейса и запускает обновление раньше
  конца ротации региона; ночные заказы Фортуны не показываются днём.
- Для прямого ответа награды сопоставляются с таблицами WFCD по региону, диапазону
  уровней, виду заказа и букве ротации из пути DE. Неизвестная ротация не заменяется A.
  Количество наград, порядок таблиц этапов и опубликованные вероятности сохраняются.
- Справочники названий, Стального Пути и трёх регионов загружаются независимо и
  кэшируются на сутки. Ошибка таблиц не убирает циклы; отсутствие всех таблиц не
  считается успешным пустым списком заказов. Возраст кэша при ошибке не продлевается.
- Новые предложения Варзии сохраняются по точному игровому идентификатору, даже когда
  WFCD ещё не знает имя. Локальный каталог даёт русское/английское название и состав реликвии.
- Заказы сохраняются в SQLite (`bounty_hunter.snapshot.v1`). После перезапуска и сбоя
  источник заменяется последним успешным снимком с явным сообщением; завершённые заказы
  исключаются. Сообщение больше не объявляет причиной отсутствие интернета.
- Определение сезона Норы читает `SeasonInfo` DE напрямую, с резервом WFCD. Сам ассортимент
  Норы по-прежнему поступает из отдельного авторизованного запроса игры.
- В журнале фиксируются безопасные события `worldstate_primary_failed`,
  `worldstate_direct_failed`, `worldstate_reference_failed`, `bounty_refresh_failed`.

Цетус и Камбион привязаны к опубликованному окончанию заказов Цетуса. Для Заримана,
Долины Сфер, Дувири и Тешина применяются те же опорные точки и периоды, что в WFCD.
Если игра изменит эти правила, их потребуется обновить; они не являются отдельными
явными полями ответа DE.

## Проверка

Реальный резервный ответ восстановил 5 циклов, 22 заказа в 3 регионах и 21 предложение
Варзии. На отдельной копии базы весь путь до моделей экранов завершился без ошибок,
неизвестных названий предложений и отсутствующих секций. Изменения пользовательской
БД и запросы торговли для проверки не выполнялись.

Для повторной проверки публичного загрузчика:

```powershell
cargo run -p platscope-providers --example check_worldstate --locked
```

Полную модель экранов можно проверить на отдельной копии SQLite:

```powershell
cargo run -p platscope-core --example check_worldstate_views --locked -- "путь-к-копии.db"
```

Пример пишет кэши только в переданную диагностическую копию. В браузере сохранённый
публичный результат доступен через `?mock=1&mockWorld=direct&mockBounty=direct`;
состояние с рабочим кэшем и ошибкой источника — через `?mock=1&mockBounty=saved-error`.
Снимки имеют исходные даты; это примеры для проверки, а не источник текущей ротации.
В фикстурах нет данных аккаунта, количество наград в инвентаре удалено.

Автотесты проверяют смену ротации на границе, устаревшие документы, ошибку 404 вместо
JSON состояния, потерю справочника наград, количество/шансы награды, кэш после перезапуска,
паузу повторов, прямое определение сезона Норы и отдельное истечение заказа Нармер.
