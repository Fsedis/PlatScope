# PlatScope 0.1.61

- Полностью переработан «Охотник за наградами»: выбор региона, читаемый список заказов и подробности с условиями получения и всеми наградами.
- Поиск сравнивает шанс получить именно нужную награду, включая Айю и другие непродаваемые предметы.
- Стоимость добычи отделена от гарантированной выплаты; неизвестные и неполные цены обозначены явно. Проверка рыночных предложений пересчитывает рейтинг, сохраняя выбранный заказ.
- Сохранены отслеживание наград, уведомления о появлении и переходы на Warframe Market. Улучшена навигация в узком окне.
- При смене ротации завершённые заказы скрываются автоматически. При задержке или ошибке источник проверяется повторно, без показа устаревших рекомендаций.
- «Состояние данных» убрано из главного меню. Диагностика, проверка источников и сохранение отчёта доступны через кнопку «Открыть диагностику» в настройках.

Обновление устанавливается через встроенный механизм или NSIS-установщик Windows x64.
