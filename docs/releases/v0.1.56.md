# PlatScope 0.1.56 — автоматическое обновление инвентаря

- Инвентарь, надетые моды и освоение обновляются автоматически после событий завершения миссий и переходов между локациями. Повторное открытие результатов не запускает лишнее чтение.
- Добавлен переключатель «Обновлять автоматически» в «Моих предметах». По умолчанию он включён; настройка сохраняется между запусками. Для обновления должны работать PlatScope и Warframe.
- Магазин Норы обновляется отдельно — только если ассортимент текущей ротации ещё не получен или срок предыдущего истёк. Успешный результат сохраняется до серверного срока ротации, в том числе после перезапуска приложения.
- Повторные события объединяются, чтения не пересекаются и ждут завершения загрузки локации. При сетевых ошибках остаётся последний успешный инвентарь, повторные попытки выполняются с паузой.
- Ограничен размер сетевых ответов, уменьшена нагрузка фонового поиска игры и уточнены сообщения при занятом сканере.

Сборка, OCR и автоматические проверки выполнены локально. Автообновление проверяет подпись Tauri. Коммерческого сертификата Authenticode нет: Windows может показать предупреждение о неизвестном издателе.

Проверка живого прохождения миссии и визуальная проверка интерфейса в этой сессии не проводились: игра не запущена, фоновый браузер недоступен. Сценарии событий игры проверены автоматическими тестами, включая обезличенную последовательность реального EE.log.
