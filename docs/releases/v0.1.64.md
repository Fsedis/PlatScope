# PlatScope 0.1.64

- В Возрождении Прайм карточки реликвий показывают количество в инвентаре, включая все уровни улучшения.
- Шанс выпадения детали выбранного варфрейма или оружия виден сразу, без раскрытия состава. Указан шанс за одно открытие без улучшения.
- Количество обновляется автоматически. Если инвентарь недоступен, вместо нуля показывается прочерк.
