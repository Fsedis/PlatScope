# PlatScope 0.1.58 — понятные фильтры инвентаря

- Поиск, тип предмета, один отбор и порядок списка объединены в видимый блок. Убраны меню «Ещё» и скрытые пересекающиеся условия.
- «Сбросить всё» возвращает полный список по названию. Старые составные фильтры из 0.1.57 не переносятся.
- Наличие копий для продажи больше не зависит от оценки цены или прогноза момента продажи. Дубликаты считаются отдельно от резерва.
- Сортировка по цене использует значение, показанное в таблице. При одинаковых значениях порядок предметов устойчивый.
- Проверка цены не переключает карточку на другой предмет при пересортировке. Возврат из карточки не прячет выбранную строку под шапкой таблицы.

Обновление подписано для встроенного автообновления. Сертификата Authenticode нет: Windows SmartScreen может показать предупреждение о неизвестном издателе.
