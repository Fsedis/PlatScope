# PlatScope 0.1.57 — обновлённые «Мои предметы»

- Переработан экран инвентаря: компактный список, поиск и форма продажи рядом, меньше повторяющихся показателей и лишних шагов.
- Основные виды «Все», «К продаже» и «Дубликаты» доступны сразу. Редкие фильтры, защита копий и расчёты цены раскрываются по запросу.
- Улучшен поиск по русским и английским названиям. Свободные копии надетых модов корректно учитываются в фильтре.
- Большие инвентари разбиты на страницы по 50 позиций. На небольших настольных окнах доступен возврат из карточки к выбранной строке.
- Проверенная цена сохраняется при обновлении инвентаря в пределах срока актуальности, а количество всегда берётся из свежего снимка. Ручная цена ордера не перезаписывается.
- При изменении инвентаря или резерва подтверждение продажи отменяется. Видимый и скрытый ордер имеют понятные отдельные подписи; лишняя галочка подтверждения убрана.
- Можно проверить цену оставленной себе копии без снятия защиты от продажи.

Обновление подписано для встроенного автообновления. Сертификата Authenticode нет: Windows SmartScreen может показать предупреждение о неизвестном издателе.
