# PlatScope 0.1.60

- Переработана вкладка «Мой план»: расходы и дополнительная выгода каждого комплекта, поиск, исключения с сохранением и пересчёт бюджета.
- Готовые комплекты открываются в продаже; путь через свои реликвии раскрывается отдельно с вероятностью, расходом копий и следов.
- Исправлено распределение стоимости общих покупок между комплектами: строки согласованы с итогом плана.
- Добавлены понятные состояния загрузки, отсутствия данных и ошибок; улучшены навигация и фокус в узком окне.
- Во вкладке «Сейчас в игре» используются оригинальные изображения Warframe вместо условных значков.
- Данные и таймеры обновляются автоматически. Кнопка повторной загрузки появляется при ошибке или задержке.

Обновление устанавливается через встроенный механизм или NSIS-установщик Windows x64.
