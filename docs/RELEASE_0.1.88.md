# PlatScope 0.1.88 — определение локации для автозапуска карты

- Карта теперь учитывает путь локации из сообщения игры об окончании загрузки. Это устраняет пропущенный способ определения миссии, из-за которого мог сохраняться статус «в Орбитере».
- Возвращение в Орбитер по этому сообщению также распознаётся: карта там автоматически не запускается.

Проверена обработка смены локации, сообщений, пришедших частями, и ручной остановки карты. Проверка выполнена локально; воспроизведение исходного сбоя на компьютере клиента отряда пока не подтверждено.
