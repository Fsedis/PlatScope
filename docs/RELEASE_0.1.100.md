# PlatScope 0.1.100 — выбор реликвий по наградам

- В разделе «Что открыть?» и на карточках разломов показывается самая дорогая возможная награда, её оценочная цена и шанс выпадения. Цена самой реликвии больше не влияет на рекомендацию открыть её.
- Улучшение реликвии выбирается по шансу получить дорогую награду в пределах доступных следов. Недостающие детали личных целей сохраняют приоритет.
- Если достоверная цена есть не у всех наград, приложение прямо указывает, что показывает самую дорогую из оценённых.
- Карточки разломов получили более ясное разделение миссии и реликвии.

Оценочная цена и шанс не гарантируют выпадение или продажу награды. Отображение и игровое поведение в установленном приложении проверяет владелец.
