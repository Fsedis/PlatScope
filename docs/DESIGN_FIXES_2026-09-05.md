Статус: исправления подготовлены для версии 0.1.48, браузерная проверка и визуальная проверка в Windows WebView2 выполнены. Проверка фактического масштаба Windows 125–150% не выполнена: пользователь явно разрешил выпуск без неё. Системный масштаб не менялся.

Основание — [20 пунктов аудита](DESIGN_AUDIT_2026-09-05.md) и просьба исправлять по приоритету. По уточнению пользователя проект остаётся настольным Windows-приложением: телефонные карточки и новая мобильная навигация не добавлялись.

## Репрезентативные данные и размеры

- Проверки выполнялись на локальном интерфейсе, без записи в реальные ордера.
- `?mock=1` — базовые данные, заполненные комплекты и дукаты.
- `mockTradeShift=1&mockOrders=27` — 27 **разных синтетических** предметов и ордеров с согласованными ключами, инвентарём и оценками; это не реальные данные аккаунта. Успех: «Проверено: 27».
- `mockLiveFailure=all` — ошибка запроса; `mockLiveFailure=stale` — устаревший запасной ответ. Во втором случае проверено сообщение «0 из 27 · не удалось: 27» и все 27 неподтверждённых строк.
- `mockSettingsError=1` — ошибка сохранения; черновик остаётся доступен.
- `overlay=1&mockOverlayState=uncertain` и `overlay=1&mockOverlayState=failed` — предупреждение и завершённая ошибка.
- Размеры браузерной области: 1180×760, 1280×720, 1536×864, 1920×1080. Таблица дукатов дополнительно 1040×760. Не каждый экран проверялся в каждой комбинации.
- Размеры 1536×864 и 1280×720 соответствуют доступной логической области Full HD при масштабах 125% и 150%, но изменение размера браузера **не является проверкой настоящего Windows DPI**. Формула компенсации DPI оверлея отдельно покрыта тестами для 1,25 и 1,5.
- Начальный прогон 27 повторов трёх позиций использовался только для длинного списка. После этого набор заменён на 27 разных позиций и повторно проверен; первоначальная фикстура не считается проверкой 27 отдельных цен.

## Автоматические проверки

- Проверка Svelte/TypeScript: 0 ошибок, 0 предупреждений.
- Заключительный прогон: 147 тестов в 21 файле прошли.
- Отладочный нативный предпросмотр собран локально; `cargo clippy -p platscope-desktop --example design_preview --offline -- -D warnings` и `cargo fmt --all -- --check` прошли.
- Отдельно прошли 5 нативных тестов геометрии оверлея (`cargo test -p platscope-desktop --lib reward_overlay_`): две–четыре награды, широкоформатное окно, сохранённые смещения и масштаб, малая высота, пятая часть комплекта. Это проверка расчётов, а не подтверждение отображения в WebView2 или поверх игры.
- Проверка пробелов в изменениях — без ошибок. Предупреждения Git о преобразовании LF/CRLF не являются ошибками содержимого.

## Нативная проверка

После явного разрешения пользователя проверка возобновлена через computer-use. Проверено отдельное окно Windows на том же движке WebView2, без настоящего аккаунта и торговой синхронизации:

- Инвентарь 1180×760: пять столбцов, переносы длинных названий, панель деталей рядом.
- Настройки: панель несохранённых изменений, модальный диалог при уходе, успешное сохранение с переходом на рынок.
- Рынок: 27 различных тестовых ордеров, «Проверено: 27», текущая цена 92p и рекомендация 89p; открытие редактора прокручивает его в видимую область.
- Охотник: раскрытая таблица наград с кнопками рынка помещается в обычном окне; проверено также развёрнутое окно.
- Карточки наград 1292×448: четыре варианта, пятая часть комплекта целиком видима, рекомендация 24p объяснена подписью «Завершит комплект» при соседнем варианте 27p.

Тестовые окна после проверки закрыты; отсутствие процесса предпросмотра подтверждено. Настройки Windows и реальный аккаунт не менялись.

Для повторения добавлен отладочный пример `design_preview`: при запущенном Vite собрать `cargo build -p platscope-desktop --example design_preview`, затем запустить `target/debug/examples/design_preview.exe`. Он использует Wry/Tao и отдельный временный профиль, не загружает нативные команды PlatScope и закрывается через десять минут либо при закрытии любого тестового окна. Зависимости доступны только для разработки на Windows. Первоначальный вариант на Tauri был пустым из-за конфликта официального `mockIPC` с неизменяемым `__TAURI_INTERNALS__`; неработающий промежуточный iframe удалён, временная диагностика в `main.ts` убрана. Это проверка отображения и поведения интерфейса, не проверка настоящего IPC или распознавания поверх игры.

## Согласованное ограничение выпуска 0.1.48

Проверка фактического масштаба Windows 125–150% сначала была перенесена перед релизом, затем прервана через Escape. На прямой вопрос о выпуске без этой проверки пользователь ответил «Да». Она не считается пройденной; размер браузерного окна её не заменяет.

OCR, настоящая сеть WFM, уведомления Windows и действия с игровым аккаунтом в этой дизайнерской проверке не тестировались. Лимитер запросов и нативный жизненный цикл оверлея в этом наборе исправлений не изменялись.
