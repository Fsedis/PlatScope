# PlatScope 0.1.84

- Карта автоматически запускается после загрузки локации. Смена локации определяется по журналу игры: старое чтение отменяется, а через три секунды после завершения загрузки запускается поиск для новой карты. При запуске PlatScope в уже начавшейся миссии учитывается последняя загрузка из журнала.
- Новые предметы теперь ищутся через реестр объектов текущей локации. Это позволяет находить экземпляры в новых областях памяти без повторного полного сканирования и сброса существующей карты. Пользовательские фильтры сохраняют приоритет.
- Для дополнительного поиска ограничены объём чтения и время обработки. Незавершённая работа продолжается в следующих проходах; большие дампы не записываются. Первоначальное чтение требуется один раз на локацию. Новая геометрия комнат этим поиском пока не добавляется.
- «Остановить карту» приостанавливает автоматический запуск до ручного включения или перезапуска приложения. Если журнал недоступен, остаётся ручной запуск.

Реестр исследован на трёх записях миссий. На записи Заримана поиск восстановил 581 дополнительный объект, включая все шесть перьев, начиная только с локального игрока. Проверены отмена старого чтения, повторные события журнала, остановка автозапуска и интерфейс на 1920×1080. Автоматический переход между локациями и скорость нового поиска ещё требуют проверки в живой миссии.
