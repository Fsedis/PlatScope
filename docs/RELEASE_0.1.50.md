# PlatScope 0.1.50

Переработанная вкладка «Реликвии».

- Компактный список своих реликвий и поиск по русскому или английскому названию реликвии либо награды.
- Для выбранной реликвии сразу показаны награды, цены, шансы и подготовка. Количество копий отделено от предлагаемого улучшения.
- Сортировка по оценочной выгоде, шансу нужной детали или количеству копий. Сравнение соло и отряда с четырьмя одинаковыми реликвиями одного улучшения.
- Улучшения за следы можно отключить. При неизвестном балансе предлагаются только уже имеющиеся улучшения.
- Из нужной награды можно перейти прямо в план соответствующего сета. При возврате сохраняются поиск и выбранная реликвия.
- Убраны повторяющиеся пояснения и отдельная сетка комплектов. Нужными считаются детали начатых сетов, а не весь отсутствующий каталог.

Оценка выгоды и вероятность не гарантируют прибыль или выпадение награды. Открытие и улучшение выполняются в игре, а не кнопками приложения.

Проверено на 141 виде реликвий в фоновом браузере при размерах 1180×760 и 1920×1080. Системный масштаб Windows не менялся.

Установщик и подпись обновления собраны локально. Коммерческого сертификата Authenticode нет: Windows может показывать предупреждение о неизвестном издателе. Встроенное автообновление проверяет подпись Tauri.
