# PlatScope 0.2.8

- Исправлено исчезновение фрагментов декретов в Дувири спустя некоторое время: карта больше не отбрасывает действующий фрагмент из-за смещения вспомогательной высоты. Точка подбора и принадлежность текущей миссии по-прежнему проверяются.
- Краткий сбой чтения положения игрока больше не удаляет сразу все найденные фрагменты. При подтверждённой смене миссии прежние точки убираются.
- Над картой добавлен переключатель «Только стрелки»: ↑ выше вас, ↓ ниже вас, небольшая точка — на вашей высоте, ? — высота неизвестна. Символы находятся прямо в точках объектов.
- Режим сохраняется между запусками и учитывает цвета групп, размеры, выбранный объект и цель. Повторное нажатие возвращает обычные значки; персонажи сохраняют прежние значки.

Причина исчезновения подтверждена чтением памяти запущенной игры. Целевые проверки смещения высоты, потери контекста и сохранённой записи памяти пройдены. Визуальную проверку карты выполняет пользователь.
