# PlatScope 0.1.94 — карта после миниобновления Warframe

- Восстановлена карта для сборки Warframe от 26.09.2026. На сохранённой миссии подтверждены локальный игрок, 25 зон, 1761 объект и 24 части геометрии.
- Профили карты теперь проверяются по цифровой подписи. При изменении сборки приложение может получить новый профиль без переустановки: загрузка допускается только после проверки подписи, адресов, типов, кода, словаря и таблиц объектов.
- Сохранено чтение записей предыдущих сборок Warframe. Неподтверждённая версия игры по-прежнему останавливает карту с ошибкой.

Проверка выполнена по сохранённой памяти. Работу карты в запущенной игре и её отображение проверяет владелец.
