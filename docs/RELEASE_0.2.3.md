# PlatScope 0.2.3

Исправлены сбой обновления рыночных цен и ошибочная отметка «В хранилище» у доступных реликвий, включая Neo C11.

- Если Warframe Market меняет адрес предмета, PlatScope переносит его сохранённые цены, историю и сопоставление инвентаря по неизменному ID. Обновление больше не прерывается из-за ссылок на прежний адрес; при конфликте предыдущие данные сохраняются целиком.
- Доступность реликвии определяется с учётом подтверждённых мест выпадения. Устаревшая отметка справочника больше не скрывает доступную реликвию. Все уровни улучшения получают одинаковый статус; противоречивые сведения без подтверждённого источника остаются неизвестными.
- После установки обновления старый справочник автоматически запрашивается заново, даже если он был загружен недавно. При недоступности источника сохраняются последние успешно загруженные данные.

Проверены обновление цен на копии и рабочей базе, сохранность инвентаря и истории за 90 дней, откат конфликтующего каталога и автоматическое обновление старого справочника. Neo C11 получает статус доступной реликвии на всех уровнях улучшения; действительно закрытые реликвии сохраняют статус Прайм-хранилища.
