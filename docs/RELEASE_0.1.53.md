# PlatScope 0.1.53

- Предмет, отсутствующий в загруженной истории аккаунта, теперь отмечается «Не освоено» вместо «Нет данных».
- Исправление применяется к сетам, плану, связанным наградам реликвий и списку освоения. Неосвоенные предметы попадают в соответствующий фильтр.
- Уже подтверждённое освоение сохраняется. Недоступная история и неподдерживаемые правила по-прежнему обозначаются отдельно.
- Цены, количества и ордера не изменены.

Сборка и проверки выполнены локально. Автообновление проверяет подпись Tauri. Коммерческого сертификата Authenticode нет, поэтому Windows может показать предупреждение о неизвестном издателе.
