# PlatScope 0.1.87 — двери Дракона на карте

- На карте миссии появились двери хранилищ, требующие ключ Дракона. Категория «Двери Дракона» включена по умолчанию.
- В названии двери указан требуемый ключ: здоровья, щитов, урона или скорости. Под русским названием сохранено английское название ключа; поиск работает по обоим языкам.
- Дверь можно выбрать целью, добавить в свой фильтр или скрыть по названию.
- Назначение определяется по требуемому ключу самого объекта. Обычные двери и действия лифтов в эту категорию не попадают.
- После обнаружения метка проверяется адресно при обычном обновлении карты. Дополнительная запись памяти на диск не запускается.

Проверено на трёх завершённых снимках двери с ключом здоровья; свойства остальных трёх ключей проверены в той же записи. Состояние открытия двери и наличие ключа у игрока пока не определяются.
