# Оригинальные изображения Warframe

Текстуры © Digital Extremes. Получены без перерисовки из зеркала игровых
ресурсов [browse.wf](https://browse.wf/). Происхождение зеркала и формат путей
описаны в [Warframe Public Export Plus](https://github.com/calamity-inc/warframe-public-export-plus#images).
Права на игровую графику принадлежат Digital Extremes, а не PlatScope.

В `sources.json` для каждого файла записаны путь внутри игры, адрес скачивания
и SHA-256 оригинальных байтов. Дата получения: 6 сентября 2026 года.

## Использование

- `cetus.png` — Остроны, `vallis.png` — Объединённый Солярис,
  `cambion.png` — Энтрати, `zariman.png` — Неукротимые,
  `duviri.png` — символ Дувири с экрана выбора стартового пути.
  Эти эмблемы обозначают локацию в заголовке карточки. День, ночь, погода,
  Фэз/Воум, фракция и настроение показываются отдельной строкой состояния;
  эмблема не выдаётся за игровой значок текущей фазы.
- `baro.png`, `teshin.png`, `varzia.png` — игровые портреты торговцев.
- `relic-lith.png`, `relic-meso.png`, `relic-neo.png`, `relic-axi.png` —
  неповреждённые реликвии соответствующей эры из ассортимента Варзии.
- `relic.png` — нейтральный игровой символ реликвии для неизвестной эры.
- `warframe.png` — общий игровой символ для отсутствующего портрета варфрейма.
- `events.png` — игровой символ уведомления о событии.

Белые эмблемы используют исходный альфа-канал как CSS-маску и цвет интерфейса.
Портреты и реликвии сохраняют исходные цвета. Все изображения включены
в приложение: внешние запросы и изменения CSP для их отображения не нужны.
